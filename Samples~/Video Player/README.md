# Video Player Sample

将 `Examples/VideoPlayer.prefab` 放入 Canvas，确保场景包含 EventSystem。入口组件为 `Yvsim.Video.VideoPlayerUGUI`。
Prefab 默认在启用时打开并播放 `Examples/mov_bbb.mp4`；可在 Inspector 替换 Clip 或 URL。

验证播放、暂停、停止、进度拖动、音量、静音及播放器铺满/恢复父容器。这里的 FullScreen 是 uGUI 布局，不是浏览器或系统全屏。
Sample 包含皮肤 PNG/PSD 和视频，公开再分发媒体前需核实各素材来源与许可；包内没有逐项授权证明。
